# HeartSync Coaching - The Woman Whisperer 💕

A complete Next.js application for relationship coaching business with client portal, payment processing, and mobile-first design.

## 🌟 Features

### 🏠 **Main Landing Page**
- **Hero Section**: Compelling "Woman Whisperer" branding
- **About Section**: Coach profile highlighting clairvoyant abilities
- **Services Section**: Three coaching packages with transparent pricing
- **Contact Section**: Multiple ways to get in touch
- **Client Portal Access**: Easy login and registration

### 👤 **Client Portal Dashboard**
- **Personal Dashboard**: Welcome message and progress tracking
- **Session Management**: Upcoming sessions with join/reschedule options
- **Message Center**: Direct communication with coach
- **Progress Tracking**: Visual progress bars for different skills
- **Achievements**: Completed milestones and accomplishments
- **Quick Actions**: Book sessions, send messages, make payments

### 💳 **Secure Payment Processing**
- **Payment Form**: Complete card processing with session selection
- **Order Summary**: Clear pricing breakdown with processing fees
- **Security Features**: SSL encryption, PCI compliance indicators
- **Multiple Payment Methods**: Visa, Mastercard, American Express, PayPal, Bank Transfer
- **Money-Back Guarantee**: 100% satisfaction guarantee

## 🎨 **Design & UX**

- **Mobile-First**: Responsive design optimized for all devices
- **Beautiful UI**: Pink/rose gradient theme with modern styling
- **Professional Branding**: HeartSync logo and consistent branding
- **Smooth Animations**: Hover effects and transitions
- **Accessibility**: Proper contrast, semantic HTML, and screen reader support

## 🚀 **Technical Stack**

- **Next.js 15**: Latest version with App Router
- **TypeScript**: Full type safety
- **Tailwind CSS**: Modern utility-first styling
- **Lucide React**: Beautiful, consistent icons
- **Responsive Design**: Works perfectly on all devices
- **SEO Optimized**: Proper meta tags and structure

## 📦 **Installation & Setup**

1. **Clone the repository**
   ```bash
   git clone https://github.com/Cyborg-Hawk-AI/heartsync-coaching.git
   cd heartsync-coaching
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)
